개인정보처리방침

내 달력 (Windows 데스크톱 앱) · 시행일 2026-11-25

1. 요약

내 달력은 사용자의 PC 에서만 동작하는 앱입니다. 별도의 서버가 없으며, 사용자의 데이터를 개발자나 제3자에게 전송·판매·공유하지 않습니다.

2. 처리하는 정보

  • 앱에서 직접 입력한 정보: 할 일 제목, 설명, 날짜, 마감 시간, 태그, 앱 설정
  • Google 캘린더 일정: Google 로그인 후, 사용자의 기본 Google 캘린더 일정(제목, 설명, 시간 등)을 읽고 앱에서 만든 할 일을 일정으로 만들거나 수정·삭제합니다.
  • Google 기본 캘린더 이름: 보통 계정 이메일 주소이며, 설정 화면에 어떤 계정과 연결됐는지 보여 주는 데에만 씁니다.

3. 사용 목적

위 정보는 오직 다음 목적에만 사용합니다.

  • 앱 화면에 할 일과 Google 캘린더 일정을 표시
  • 앱의 할 일과 Google 캘린더 사이의 동기화
  • 마감 10분 전 Windows 알림

4. 저장 위치와 보관

  • 할 일, 태그, 설정, 표시용 Google 일정 사본은 사용자 PC 의 %APPDATA%\com.todocalendar.app\ 에 저장됩니다.
  • Google 로그인 토큰은 Windows 자격 증명 관리자에 저장됩니다.
  • 데이터는 사용자가 앱을 삭제하고 위 폴더를 지우거나, 앱에서 로그아웃할 때까지 사용자 PC 에만 보관됩니다.
  • 앱이 통신하는 곳은 Google 로그인·Google Calendar API 서버뿐입니다.

5. Google API 데이터 사용

이 앱이 Google API 로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한된 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. Google 사용자 데이터는 광고에 사용하지 않으며, AI·머신러닝 모델 학습에도 사용하지 않습니다.

6. 권한 철회와 데이터 삭제

  • 앱의 설정 → 구글 캘린더 → 로그아웃을 누르면 토큰이 삭제되고 Google 쪽 권한도 취소됩니다.
  • Google 계정 → 타사 액세스에서도 언제든 권한을 취소할 수 있습니다.
  • 앱을 제거한 뒤 %APPDATA%\com.todocalendar.app\ 폴더를 지우면 로컬 데이터가 모두 삭제됩니다.
